A12只放行A1：Q01、Q07—Q09、Q12—Q16、Q18—Q24共16情景，其中Q18仅是手工提供的多源材料；至少4个保留变体在此子集内，其余2个保留变体覆盖历史/表。Q02—Q06、Q10—Q11、Q17共8项需A2，其中Q06可有A1手工对照练习但不计A2通过。A12等待A11，依赖闭包包含A10；Q24在A12验证临时目录的领域库备份恢复/保留，服务器备份与恢复操作证据归D02。D03激活前在准确合并tree重跑16情景、关键语义case各3次；全off部署不等于激活放行。D04用含A09的候选跑完整24情景、全部6保留变体；基础自动情景全部运行，适用关键语义case各3次真实模型运行。D05/D06重验受影响A情景，加B/C专项，并重跑D01的stage隔离、真实平台及恢复三个门槛。

关键case至少3次独立模型运行，记录所有attempt，不挑最好结果；至少覆盖完整性缺失、幻觉引用、矛盾事实和注入。API实际模型可核验方式按provider返回证据固定；只返回别名或不能确认时标unverified，不冒称指定SOTA。生产业务模型与工程Codex/Fable分开配置。

## A1与A2分别的真实验证

A1：指定测试账号贴材料→受理卡→真实模型→草稿→纠错→采用→查看当前版本；手机和桌面各一轮；别的账号/转发卡不可查看正文。无业务表写入、无群分享。

A2：选择授权群、历史日期和必要表，验证分页覆盖、thread、媒体缺口、获取身份、请求者成员或实际资源ACL。Bot能读不自动代表用户能读；只有成员可访问的群先证明实时成员关系，若群历史策略限制更细则按实际用户权限读取。P2P/文档/Base分别验证各自可见性，不能用“在某群”替代全部资源ACL。能力不足时仅开放用户手工提供或当前范围可证明的资料。

出网前、每次新读取、生成结果提交与发送前校验有效grant；源记录删除/撤回通知或最终可访问性探针使revision stale。复查失败或无当前授权证据保留needs_input。事后发现撤回不能回收已提交给模型的prompt或已经发送的卡片；用户可见说明、保留政策及provider处理约定需纳入试点配置。

## L2精确故障切点

在事务提交前/后、模型调用前/后、outbox创建后/发送前、provider effect后/本地ack前、receipt创建前/后逐点中断。lease建议30秒、10秒续租，认领后取数/生成总墙钟180秒（包括初次与最多2次重试，不重置deadline），心跳独立于阻塞模型调用；同一有效owner_id+epoch/fence才能续租/提交。每次续租失败停止后续IO并丢弃不可提交结果。超时杀死并等待CLI子进程/进程组退出；网络模型取消只表示客户端停止，不保证服务端停止计费。

恢复generating任务时必须先核对来源仍可用、grant仍有效和快照TTL；满足才复用原快照。否则needs_input，不自动读取新资料作为“同一次任务”。只读生成允许初次加最多2次明确可重试attempt，均受同一个180秒deadline约束；外部写/发送不套用这条重试规则。

## 质量与试点标准（建议值，启动时确认）

- 确定性计数、来源映射和权限反例全部精确通过。高风险越权/错接收人/错写/重复外发观察事件为0；任何一次阻止扩量，不拿平均得分抵消。
- 关键事实、负责人承诺与日期：必须有支持来源，或标待确认；引用存在不算语义支持。人工核对关键断言支持率100%；非关键断言支持率≥95%；核心待决事项召回≥90%。分母、冲突裁定和missing样本在评测清单明确，样本小不推断总体可靠性。
- 试点前先人工完成3份同类任务计时；至少7天且10个不同真实委托。报告提交总数、用户接受数、核验成功数、拒绝/弃权、修订分钟、延迟、成本。
- 建议退出目标：≥8/10委托用户认为可用；准备+修订总时间中位数较匹配人工基线减少≥30%；关键事实无严重失实。若样本分布差异大则记录不可比较，不宣称提效。
- 工程SLO初值：受理反馈P95≤3秒、500消息内成功任务P95≤120秒，并列失败/超时总数和比率，不从SLO分母隐藏失败、队列等待不算模型生成时长但单列。长任务180秒硬超时后明确失败；Monitor health/控制响应不能被阻塞。样本少于20时不据P95作统计推断，报告每次耗时和最大值。
- 成本须有每任务上限和每日上限，试点预算owner配置；每任务限额纳入不可变评测参数，每日限额只入config hash/审计，不改变单任务可比性键，因日限额缺测须单列；超过上限停止新调用并保留草稿状态。对外部provider账单未知时标unknown，不补0。

```bash
uv sync --all-extras --locked --python 3.11
```

候选版本再执行容器smoke：

```bash
OSTAG_RUN_CONTAINER_SMOKE=1 scripts/release_check.sh
```
